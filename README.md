## 🚀 Quick Start — Advanced BMI Calculator

Navigate into the project folder and run:

```powershell
cd Python-Programming-Advanced-BMI-Calculator
python -m pip install -r requirements.txt
python bmi_calculator.py
```

To run all automated unit tests:
```powershell
python -m unittest discover -s tests -v
```

For full documentation, architecture details, and usage guides, refer to [`Python-Programming-Advanced-BMI-Calculator/README.md`](Python-Programming-Advanced-BMI-Calculator/README.md).
